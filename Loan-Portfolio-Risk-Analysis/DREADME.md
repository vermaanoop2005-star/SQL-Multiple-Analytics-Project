# Loan Portfolio & Risk Analysis System

## Project Overview

A SQL-based analytics project focused on analyzing loan portfolio performance, customer profiles, loan applications, credit risk, and repayment-related metrics.

The project demonstrates how SQL can be used to transform loan data into meaningful business insights and support data-driven decision-making.

## Business Objectives

* Analyze loan applications and loan status.
* Evaluate loan disbursement and outstanding amounts.
* Identify customers with higher loan exposure.
* Analyze credit scores and risk categories.
* Study overdue payments and default customers.
* Compare loan types and city-wise loan performance.
* Calculate important business KPIs.
* Analyze loan application and approval trends over time.
